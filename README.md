# Alloy Client
A recreation of the [7.0 RotMG Client](https://github.com/moistosaurus/realm-cli) written in C# using OpenGL via OpenTk


# Alloy Server

The server this client connects to out of the box can be at the sister project over at [Zolmex/alloy-server](https://github.com/Zolmex/alloy-server)
